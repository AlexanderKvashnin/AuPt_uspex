This is a code receives the address of the cluster folder and the substrate file as input
reads the symmetry of each cluster
creates a certain number of configurations depending on its symmetry. 

The lower the symmetry, the more configurations there are. 
If there is a lack of symmetry elements, the number of different configurations is compensated by random ones. 

The cluster is also aligned relative to the substrate at a certain distance from it. 
At the output, we have ready-made configurations of all clusters along with the substrate.
